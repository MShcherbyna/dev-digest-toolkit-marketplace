# Changelog

All notable changes to this plugin are documented here. Versions follow [SemVer](https://semver.org).

## [1.0.0] - 2026-10-20

- First release: the `researcher` agent for repository and web research, with interview mode and cited report formats.
- Truly read-only: `tools` is limited to Read, Grep, Glob, WebSearch and WebFetch (no Bash).
