# Changelog

All notable changes to this plugin are documented here. Versions follow [SemVer](https://semver.org).

## [1.0.0] - 2026-10-20

- First release: 13 skills for React, Next.js, React Testing Library, Fastify, Drizzle ORM, PostgreSQL, TypeScript, Zod, onion architecture, web security, Mermaid diagrams and module-local engineering insights.
- Skills are project-neutral: project paths come from the repository itself or the optional `.claude/sdd-engineering.json`.
- Third-party skills carry their source and license in frontmatter `metadata` and in `THIRD_PARTY_NOTICES.md`.
